Kelas 5 SD/MI – Pembelajaran Interaktif & Real-time Monitoring

📖✍️🧠🌟✏️

Jelajahi keunikan diri, dunia buku yang luas, dan ekspresikan hobimu lewat bahasa yang indah!

Aplikasi ini siap dihubungkan dengan Firebase Console anda.

  1. Buat project baru di Firebase Console.
  2. Aktifkan Authentication (Email/Password & Anonymous).
  3. Buat database Cloud Firestore (atur ke Test Mode atau Security Rules sesuai dokumentasi).
  4. Masukkan konfigurasi di bagian script variabel firebaseConfig pada file ini.
  5. Akun Guru dapat didaftarkan langsung atau dibuat di Auth Console.
